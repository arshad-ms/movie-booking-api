## Sprint 1: Project Initialization & Infrastructure (The "Workshop" Setup)
**Goal:** Establish the development environment, version control workflow, and prove the basic toolchain works.
**Key Deliverables:**
- Installation of JDK 21, IntelliJ IDEA, Git, and PostgreSQL.
- Generation of Spring Boot project via Spring Initializr (with Spring Web dependency).
- Creation of a GitHub repository and configuration of local Git.
- Implementation of a simple `HelloController` (`/hello` endpoint) to verify the server runs.
- Successful `git push` of the foundational codebase to the remote repository.

**Definition of Done (DoD):**
- Project compiles without errors locally.
- Accessing `http://localhost:8080/hello` returns a successful JSON response.
- Code is safely stored in the cloud (GitHub).
